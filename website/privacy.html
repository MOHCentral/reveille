Privacy

What Reveille sends, and where.

Last updated 15 October 2026

Reveille is a free, open-source launcher maintained by volunteers. It has no accounts and no ads, and it does not sell or share data. This page covers the Reveille desktop app and this website. The command-line tool never sends usage statistics.

Usage statistics and crash reports

The desktop app sends anonymous usage statistics and crash reports so we can see where new players get stuck. They are on by default. Turn them off in Settings › Privacy; from then on nothing more is sent, and the random installation ID described below is deleted.

The app records events such as:

  • the app started, the previous run crashed, or Reveille was updated;
  • a game folder was found, and first-time setup finished;
  • installing OpenMoHAA or Reborn started, finished or failed;
  • the server list loaded or failed, and a server was selected;
  • a map or mod download started, finished or failed;
  • Join was pressed, the game started or failed to start, and how long it ran (under a minute, up to ten minutes, or longer);
  • server admin tools were used (the kind of command only);
  • a server alert was set, shown or used.

Each event carries a random installation ID, a random session ID, the Reveille version, the operating system (Windows or macOS) and a timestamp. The installation ID is created at random on first launch. It is not derived from your hardware, account or files. Failures are reported as short codes such as download_failed; crash reports carry a source file and line, never the error text.

Reveille never sends player names, server names or addresses, server passwords, CD keys, your Windows username or computer name, folder paths, error messages or your server history.

Events go to PostHog, in its EU region. IP-based location lookup is turned off for every event, and the PostHog project discards client IP addresses. Every event the app can send is defined in one source file, telemetry/mod.rs, so anyone can check this list against the code.

Services the app talks to

To do its job, Reveille connects to these services. Like any internet connection, each one sees your IP address. Reveille sends them only what the request needs.

  • 333networks master server (master.333networks.com), for the list of public game servers.
  • Game servers in that list, which Reveille asks for their status, players and map.
  • moh-db.com, to find and download maps and mods.
  • A game server's own download list, when that server publishes one.
  • GitHub, to check for Reveille updates and to download Reveille, OpenMoHAA and Reborn.

Discord status

If you choose to share it, Reveille tells the Discord app on your computer which game you are playing and the server's name, so your Discord friends can see it. This is off until you turn it on, and it goes only to your local Discord app, which shares it under Discord's privacy policy.

On your computer

Your settings, favourite servers and alerts are stored on your computer and are not sent anywhere. Server-admin passwords are kept in your operating system's credential store, not in Reveille's own files.

This website

This site is hosted on GitHub Pages, which may log visitors' IP addresses under GitHub's privacy statement. The page asks the GitHub API for the latest release so it can show the current version. It sets no cookies and has no analytics.

Questions and requests

Because the data is anonymous, we cannot link an event to you. To ask a question or make a request about your data, open an issue on GitHub. If this policy changes, the new version will appear on this page with a new date, and the full history is in the repository.
