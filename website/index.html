How it works

From game folder to launch.

Reveille works with the game files you own and handles the setup around them. It does not include EA game data.

You need Medal of Honor installed.
Install Allied Assault from disc, EA App or GOG first.

  1. 1

    Find your game

    Reveille checks common Windows locations. If it misses yours, choose the folder.

  2. 2

    Choose your engine

    Keep Original or choose OpenMoHAA or Reborn. Reveille installs the supported build when needed and remembers your choice.

  3. 3

    Pick a server

    See who is playing where. Filter to servers that are ready to join, star favorites, or watch a quiet server until players show up.

  4. 4

    Get the maps and join

    Reveille shows what the server needs and the download size, gets the matching moh-db packages, then starts the game on that server.

Run a server?

Let players arrive with your maps.

A missing custom map is an easy way to lose a new player. Reveille reads what your server already publishes and fetches the maps before it connects them.

  • 01

    Publish your map list

    Set sv_maplist to your full rotation. Reveille checks every map in it, not only the one running now, so a map change does not leave new players behind.

  • 02

    Put custom maps on moh-db

    If your maps are on moh-db under the names your server uses, Reveille can match and install them.

  • 03

    Or host them yourself

    Servers that publish a PakRadar list through pr_downloads can hand players their own files. Reveille checks each one against its published checksum.

Field notes

Before you download.

Does Reveille include Medal of Honor?

No. You need a legitimate Allied Assault installation. Reveille identifies and works with your existing game files; it never redistributes EA assets.

Do I need to find patched binaries myself?

No. Keep the Original game or install OpenMoHAA or Reborn from Reveille. It gets the current supported package, checks that the download arrived intact and remembers which engine to launch.

Where do the missing maps come from?

From moh-db.com, or from the server itself when it publishes its own download list. Reveille installs an exact match when you approve the download, asks you when several files could fit, and says when no download is listed.

What does “Ready to join” mean?

The server answered just now and you already have the map it is running, so there is nothing to download. Reveille starts the game with the server’s address; the server still decides whether you get in, for example when it is full or has a ping limit.

How do player alerts work?

Watch a server and pick how many players you want. While Reveille is open, or waiting in the notification area if you turn that on in Settings, it checks the server and sends a Windows notification when enough players are on.

Does it need Administrator rights?

The Reveille installer is per-user and does not need Administrator rights. Writing maps into some protected retail game folders can still be blocked by Windows; Reveille reports that instead of raising a surprise UAC prompt.

Why might Windows show a warning?

The current release is not code-signed, so Windows names no publisher and SmartScreen may hold the download. The release page publishes the installer’s SHA-256 for checking download integrity.

Is it open source?

Yes. Reveille is free and licensed GPL-3.0-only. The source, issue tracker and release history are public on GitHub.
